# Official Travel Report

## What This Does

Reads all source documents from a designated folder and synthesizes them into a complete Official Travel Report with four required sections, following standard government/institutional report writing conventions. Every claim is evidence-based — gaps are flagged explicitly rather than filled with assumptions.

## When to Use This

Use this skill when you need to:
- Write an official travel report after attending a conference, summit, workshop, or standards meeting
- Synthesize invitations, programs, notes, slides, and articles into a structured report
- Produce a compliant travel report with S&T impact categories
- Document linkages and follow-through actions from official travel

## How to Use

Point the agent to a folder containing your travel source materials:
- **"Write a travel report from the files in [folder]"**
- **"Generate an official travel report using the documents in [folder]"**
- **"Synthesize my trip materials into an official travel report"**

### Source Materials (any combination)

- Invitation letters or official correspondence
- Program of activities / agenda
- Event briefers or concept notes
- Presentation slides
- Personal notes or trip reports
- News articles or press releases
- Calling cards or contact information
- Photos with captions

## What You'll Get

A complete travel report draft with:

1. **Header** — Activity title, date, venue
2. **Section 1: Highlights/Major Decisions** — Event overview, day-by-day chronological account, and S&T impact categories (8 possible, only applicable ones included)
3. **Section 2: Recommended Follow-Through Actions** — Follow-up activities and local application of technologies learned
4. **Section 3: Impressions/Observations** — Professional reflection on field developments, host country S&T status, and notable discussions
5. **Section 4: Linkages Established** — Professional contacts documented during the trip
6. **Gaps & Flags Summary** — Consolidated list of all `[NEEDS INPUT]` placeholders for the writer to address before submission

## Key Principles

- **Evidence-only writing** — nothing is invented or assumed
- **`[NEEDS INPUT]` placeholders** — inserted wherever source documents are insufficient
- **S&T impact categories** — only included when clearly supported by evidence
- **Formal third-person tone** — consistent with government/institutional report conventions
- **Depth over brevity** — Section 1 is thorough, with multiple paragraphs per day for dense events

## Example Usage

**You:** "Write a travel report from the files in ./travel/ISO-TC307-Bangkok/"

**Agent:** *Reads all source documents, inventories coverage, then drafts the complete four-section report with a Gaps & Flags summary at the end.*
